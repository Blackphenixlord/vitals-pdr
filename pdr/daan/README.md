# D.A.A.N. — Daily Accountability and Activity Notebook

The official format (HUNCH Generic Schedule). One notebook per person; the project manager
(Joshua) assembles the team summary with highlights.

**Write it the day you work. Never back-fill.** A judge can tell, and it's the one deliverable that
can't be fixed later. Copy [`TEMPLATE.md`](TEMPLATE.md) to `daan/<your-name>/<YYYY-MM-DD>.md`, or keep
it in a Google Doc with the same headings — just be consistent.

## Contents (from the HUNCH list)

- Title page — course, year and quarter, a picture you choose, your first and last name
- Table of contents — automatically generated (Google Docs: Insert → Table of contents)
- A **new page each day** you work on the project
- Each page: Header 1 with the date (range), then the four questions below
- Lots of pictures, CAD, drawings, notes, test results and video

## Supporting evidence (not entries)

[`project_history.md`](project_history.md) is the dated git history of the code. It shows **what was
built when**. It is evidence you can point to from your own entries ("see commit 646e64b") — it is
not a substitute for them.
