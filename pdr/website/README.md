# Website

`index.html` is the whole site — one file, no internet needed to view it, works on a phone.

## Hosting it (pick one)

The repo is **private**, so GitHub Pages on this repo needs a paid plan (or GitHub's free student
pack). Simplest options:

1. **Your existing site** — copy `index.html` into the `Blackphenixlord.github.io` repo as
   `vitals/index.html` → `https://blackphenixlord.github.io/vitals/`.
2. **Google Sites** — the HUNCH list allows a Google Site; paste the sections in.

Then: `python pdr/website/make_qr.py <url>` → `qr.png` for the header board. Scan it before printing.

Before PDR: replace the Videos line with the two uploaded video links.
